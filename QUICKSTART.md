# Быстрый старт демон-сервиса

## Проблема решена! ✅

Теперь модели загружаются **один раз** при запуске демона и остаются в памяти.

## Как использовать

### 1. Запустите демон (один раз)

```bash
sh start_model_service.sh v1.5 normal 0
```

Демон загрузит модели в память и будет ждать запросы.

### 2. Отправляйте запросы (многократно, быстро!)

```bash
sh inference_fast.sh ./configs/inference/test.yaml v1.5 normal
```

Модели уже в памяти - обработка начинается сразу!

### 3. Остановите демон (когда закончите)

```bash
kill $(cat ./logs/model_service_v1.5_normal.pid)
```

## Что изменилось?

**Раньше:**
- Каждый запуск `inference_fast.sh` → загрузка моделей (~30-60 сек)
- 10 запросов = 10 загрузок = **5-10 минут потеряно**

**Теперь:**
- Один запуск демона → загрузка моделей один раз (~30-60 сек)
- 10 запросов = без загрузки = **экономия 4-9 минут!**

## Проверка работы

```bash
# Проверить, что демон работает
ps aux | grep model_daemon_service

# Посмотреть логи
tail -f ./logs/model_service_*.log
```
